# Customer Churn Analysis

## Project Overview
This project analyzes customer churn data to understand customer behavior and identify factors that may be associated with customer churn.

## Objective
- Analyze customer demographics and subscription details.
- Examine customer tenure and monthly charges.
- Identify patterns related to customer churn.
- Prepare cleaned data for analysis.
- Summarize important findings from the dataset.

## Dataset
The dataset contains customer information including:
- Customer ID
- Gender
- Age
- Tenure
- Subscription Type
- Monthly Charges
- Total Charges
- Contract Type
- Support Tickets
- Payment Method
- Churn Status

## Data Preparation
The dataset was cleaned and prepared for analysis. The cleaned dataset is available in:

`customer_churn_cleaned.csv`

## Analysis File
The Excel analysis file is available as:

`customer_churn_analysis.xlsx`

## Data Quality Summary
A data quality summary is included in:

`data_quality_summary-1.md`

## Conclusion
Customer churn analysis can help identify patterns in customer behavior and support better customer retention strategies.
